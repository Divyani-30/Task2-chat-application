#DESCRIPTION
his project is a real-time web-based chat application developed using Node.js, Express, and Socket.IO. It allows multiple users to join a chat room, exchange messages instantly, and see live updates without refreshing the page. The front-end interface is built using HTML, CSS, and JavaScript, offering a clean and responsive user experience.
The real-time communication is powered by Socket.IO, which enables bi-directional WebSocket connections between the client and server. Each user is automatically assigned a temporary username (e.g., "User-321"), and messages are sent and received instantly using WebSocket events. The application also displays system messages when a user joins or leaves the chat room, enhancing interactivity.
Additional features include message styling for differentiation (e.g., "You" vs. others), support for sending messages using the Enter key, auto-scrolling chat display, and clean UI enhancements for a better user experience.
